DG 懸浮面板大路推薦 V30｜2026-09-25

基底：V29（對子機率 25% / 7%）
本版只改主懸浮面板「建議」的莊/閒推薦邏輯；對子、和局推薦、即時資料、拖曳縮放與手機版版面均保留。

每房獨立、即時同步：
- RB01 / RB02 / RB03 / RB04 / RB05 / S01... 各自只使用本房即時 results / 大路。
- 每次該房大路有新的莊/閒結果，立即重新分析並更新「建議」。
- 和局不新增莊/閒大路柱，因此不推進以下柱型節奏。

規則：
1. 齊頭
   - 不限制 3 或 4 高度。
   - 目前新柱比前一柱矮時，推薦目前新柱同一邊，直到補到前柱高度。
   - 例：3閒｜2莊 -> 推薦莊；5莊｜2閒 -> 推薦閒。

2. 單跳
   - 最少 3 顆交替才成立。
   - 莊｜閒｜莊 -> 推薦閒；閒｜莊｜閒 -> 推薦莊。

3. 1房2廳 / 2房1廳
   - 最少第 5 顆，完整形成 2-1-2 後才成立。
   - 2莊｜1閒｜2莊 -> 推薦閒；若開閒，後續推薦莊、莊。
   - 反向完全對稱。

4. 雙跳
   - 4 顆（2-2）即可成立。
   - 2閒｜2莊 -> 推薦閒；若第一顆開閒，再推薦閒補成 2閒。
   - 反向完全對稱。

優先順序：
- 1房2廳/2房1廳 -> 單跳 -> 雙跳 -> 齊頭 -> 隨機莊/閒。
- 明確節奏優先於一般齊頭，避免 2-1-2-1 被齊頭邏輯蓋掉。

失效 / 隨機規則：
- 只要原規律因實際開獎而被打破，當下大路不再符合該規律，立即回到隨機莊/閒。
- 隨機結果對相同房間 + 相同大路保持穩定，避免倒數或其他即時欄位刷新造成畫面推薦閃動。
- 待該房大路重新形成上述任一有效路型，再由該路型接管推薦。
